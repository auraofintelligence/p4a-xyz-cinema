# Markdown builder field correction

Reviewed 2 November 2026, Australia/Brisbane.

The public noticeboard's “Private or excluded material” field previously copied its contents into the same downloadable Markdown file. Related builder modes repeated that pattern. The fields and corresponding output sections have been removed from the public noticeboard, civic profile and twelve shared builder modes.

The forms now ask only for content the person wants in the file, with a short reminder to leave private or excluded information out. Scope, review and consent fields remain available; they describe intended use rather than implement access control.

Old session drafts are not erased on opening. Retired fields are no longer restored into the form or included in Markdown; normal editing saves the remaining displayed fields. Copy, download and clear behaviour remain unchanged. No network publishing or account feature was added.

Validation includes all fourteen builder modes with legacy-field sentinel values, ordinary edit/clear tests, JavaScript syntax, the existing aggregate checks and 2,081 place contracts. The live publication result is recorded separately in Git history and Pages status.
