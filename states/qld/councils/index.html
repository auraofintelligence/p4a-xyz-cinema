    What the map describes

    The official Queensland pastel raster shows actual coastlines, islands and places with subdued grey roads. Detailed roads switch to the official topographic style. Actual council polygons are a transparent overlay, including administrative water areas. Both share the same EPSG:3857 coordinates, aligned using the service's returned image extent. No SVG, traced outlines or synthetic geography. The retained PNG works locally; zoom-specific detail loads from the official Queensland map service when online. The boundary source contains 77 councils plus Weipa Town Authority. Only Redlands has a completed P4A local journey in this pass. Use ECQ's address finder for official electoral enquiries.
